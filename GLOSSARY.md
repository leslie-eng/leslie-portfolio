# Leslie's Portfolio

Leslie Angu's personal portfolio site — a recruiter-facing, non-commercial showcase rebuilt in this repo and deployed free on Vercel (Hobby plan). Headline identity: Data Engineer.

## Language

**Portfolio**:
This site: the personal, non-commercial showcase deployed on Vercel's Hobby plan, aimed at recruiters and hiring managers for full-time roles.
_Avoid_: website (too generic), personal site, resume site

**Featured Project**:
One of the 3–6 projects shown on the Portfolio, each with its own Case Study. Featured Projects are chosen to prove the Headline first, then Range.
_Avoid_: showcase item, work sample

**Flagship**:
The Featured Project that leads the gallery and anchors the site's narrative: Address Yangu. Exactly one Flagship at a time.
_Avoid_: key product, hero project

**Address Yangu**:
A housing-vacancy platform — tenant search and caretaker management on the web, plus hardware units installed on buildings in the field. Kinetic Kraft Robotics' first project. The Flagship. Production code is private; the public `address_yangu_version_2` repo is the open demo build.
_Avoid_: address-Yangu (repo spelling), AY

**Kinetic Kraft Robotics**:
The robotics startup Leslie founded. Address Yangu is its first project.
_Avoid_: KK, the company

**Evidence**:
The artifact that proves a Featured Project is real: a live URL, installation photos, or a public repo. Every Featured Project needs at least one.
_Avoid_: demo, proof

**Case Study**:
The standard write-up format for every Featured Project: problem → approach → stack → outcome. Lives on its own page.
_Avoid_: project description, README dump

**Headline**:
The single discipline the Portfolio leads with (Data Engineer). One Headline only; everything on the site is sequenced to support it.
_Avoid_: primary skill, main focus

**Resume**:
The single downloadable CV the Portfolio hosts, built from the data-engineer CV as its base. Only one exists on the site.
_Avoid_: CV (a CV is one of the source documents in `cvs/`, not the site artifact)

**Range**:
The supporting disciplines (embedded systems, full-stack software) demonstrated beyond the Headline. Range never competes with the Headline for attention.
_Avoid_: secondary skills, other hats
