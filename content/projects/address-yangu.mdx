## Approach

I founded **Kinetic Kraft Robotics** to build the whole loop: a device on the building, a platform in the middle, and a tenant on the other end.

- **The device.** The AY-NVD2 gate unit runs on an STM32F407 with FreeRTOS: a touch display, LTE modem, GPS, EEPROM and real-time clock. Eight tasks with fixed priorities talk over three queues. A single modem task owns the LTE link and posts HTTPS requests in order.
- **The platform.** A React PWA with phone and OTP login. Tenants search by unit type, price and area — or by current location, sorted by walking distance on an OpenStreetMap map. Caretaker contacts are revealed only after a token unlock.
- **The caretaker side.** Vacancy management for the person who actually knows: mark units open or occupied and keep the listing honest at the source.
- **The demo build.** The public repo is a trimmed, runnable version of production (mocked OTP, no paid map keys). Production adds PostGIS spatial queries, SMS/USSD via Africa's Talking, M-Pesa payments and the device integration.

## Data quality & testing

- **Host-side test suite.** The firmware core compiles for both the target and a desktop host. A FreeRTOS shim and a mock hardware layer run the verification suite and a full-system simulation with `make host`, with no board needed.
- **Two-layer watchdog.** Every task checks in against its own deadline. The supervisor refreshes the hardware watchdog only when all of them have, so one stalled task forces a clean reset within ~8 s.
- **No lost events.** When LTE drops, requests are written to an EEPROM ring queue and replayed when the link returns.
- **Debounced input.** Physical buttons and touch both require a 300 ms hold, so stray presses don't flip a unit's status.
