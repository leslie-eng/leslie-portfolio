## Approach

Accountability needs teeth: visible streaks, real consequences, and something paying attention every day.

- **Daily loop.** Members join challenges and submit code or a link to an article they wrote. Submissions earn points and streaks, and challenge and global leaderboards make progress public.
- **AI grading with a rubric.** Article submissions are graded by Claude against an explicit rubric, so feedback is consistent from week to week.
- **The Friday Drop.** A timezone-aware weekly digest at 08:00: notes, a vote on member-proposed projects, and a timed quiz of 10, 20 or 30 minutes. The first Friday of each month adds an interview-prep quiz per specialisation.
- **Nudges.** A nightly job finds members falling behind and can send a WhatsApp nudge. Admins get a weekly digest of the cohort's health.
- **In-browser code.** Python runs via Pyodide and JavaScript in a sandboxed worker, inside the member's browser and never on the server.

## Data quality & testing

- **70 pytest tests across 6 modules** — API, coding exercises, grading, learning materials, quizzes and the weekly drop.
- **CI on every push.** GitHub Actions runs the backend suite and the frontend lint and build in parallel, and cancels superseded runs.
- **Deterministic external services.** Tests use fakes for the LLM and WhatsApp, and a throwaway SQLite file, so the suite needs no credentials and gives the same result every run.
- **Human in the loop.** Generated quizzes and exercises go through an admin review screen before members see them.
- **Startup checks.** The API checks its configuration at boot and refuses to start half-configured.
